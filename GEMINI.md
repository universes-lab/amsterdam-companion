Памятка разработчику "Самураю Кодинга" Gemini CLI:

После завершения каждого этапа работы я обязан выполнить push_github.bat и зафиксировать изменения отдельным коммитом.

Перед любым рискованным изменением я обязан определить последний стабильный commit через git log --oneline и зафиксировать его в своем логе.

Инструкция (пример):
Что должен делать Самурай после каждого этапа
Всего одна команда:
push_github.bat
и вводит:
RUN-001
или
RUN-002
или
SEARCH-001

Что делать при откате
Самураю достаточно знать три команды.
Посмотреть историю:
git log --oneline

Откатить файл:
git checkout COMMIT_HASH -- filename.py

Полный откат проекта:
git reset --hard COMMIT_HASH
